# ثقة كار (Thiqah Cars) — Dealership Showcase Platform

[![Live Demo](https://img.shields.io/badge/Demo-Live_on_Vercel-blue?style=for-the-badge&logo=vercel)](https://thiqah4-cars.vercel.app)
[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg?style=for-the-badge)](LICENSE)
[![RTL Supported](https://img.shields.io/badge/Language-Arabic_(RTL)-orange?style=for-the-badge)](#)

A modern, responsive bilingual vehicle dealership showcase and pre-owned car verification platform designed for seamless car browsing, inspection transparency, and buyer inquiries.

---

## 🌟 Key Features
- **Native Arabic (RTL) Layout**: Polished typography and layout optimized for right-to-left reading flow.
- **Responsive Vehicle Catalog**: Interactive car listings with high-resolution imagery, specifications (mileage, engine, transmission), and pricing breakdown.
- **Verification & Inspection Assurance**: Dedicated badges and checklist transparency to foster buyer confidence.
- **Instant Inquiry Call-to-Action**: Direct WhatsApp and phone contact integrations for instant test-drive scheduling.
- **Fast Static Delivery**: Zero-dependency static architecture ensuring instant load times and 100/100 Lighthouse performance.

---

## 🛠️ Built With
- **HTML5 & CSS3** — Semantic structure and modern CSS styling.
- **Tailwind CSS** — Utility-first styling for agile layout and responsive breakpoints.
- **Vercel** — Automated deployment pipeline and global edge hosting.
